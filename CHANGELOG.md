# Changelog

## 1.0.0

First packaged Windows release.

- Small edge marker with proximity-triggered checklist.
- Today and Later lists, inline entry and completion animations.
- Responsive text fields, draggable detail editor and editable hover cards.
- Monochrome calendar and longer memo support.
- Completion archive, restore, chronological Markdown and JSON export.
- Local JSON storage with a previous-save backup.
- Taskbar and Alt+Tab exclusion; system tray controls.
- Self-contained Windows x64 distribution with integrity checksum.
