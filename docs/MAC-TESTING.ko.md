# SideTodo Mac · 친구 테스트 안내

## 설치와 첫 실행

1. `SideTodo-1.1.0-mac-preview.2-universal.zip`을 압축 해제합니다.
2. `SideTodo.app`을 응용 프로그램 폴더로 옮기고 실행합니다.
3. 화면 왼쪽 위에서 조금 아래에 있는 작은 바 근처로 마우스를 옮깁니다. 메뉴 막대의 체크 아이콘에서도 열 수 있습니다.

macOS 13 이상을 대상으로 하며 Apple Silicon(M1 이후) / Intel을 한 앱에 포함했습니다.
현재는 Developer ID 서명·Apple 공증이 없는 테스트 버전이라 첫 실행 시 경고가 나올 수 있습니다. 배포자를 신뢰하고 파일을 확인한 경우 앱 실행을 한 번 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 이용하세요. Mac 전체 보안 설정을 끄거나 터미널로 검역을 일괄 해제할 필요는 없습니다.
악성코드 감지나 파일 손상이라는 경고가 나오면 진행하지 말고 정확한 메시지를 전달해 주세요.
공식 안내: https://support.apple.com/en-us/102445

## 사용

## 이전 버전에서 업데이트

1. 메뉴 막대에서 기존 SideTodo를 종료합니다. 작성 중인 새 일정은 먼저 추가해 주세요.
2. 응용 프로그램 폴더의 `SideTodo.app`만 새 앱으로 교체합니다.
3. 실행하면 기존 일정과 완료 기록을 그대로 불러옵니다. 데이터 폴더를 삭제하거나 청소 앱으로 제거하지 마세요.

저장 위치와 JSON 형식, 앱 식별자는 이전 버전과 같습니다. 새 버전은 첫 실행 시 기존 `tasks.json`을 `tasks.before-preview2.json`으로 한 번 복사해 별도 보관합니다. 이 백업은 이후 저장 때 덮어쓰지 않습니다. 평소 저장용 `tasks.json.bak`도 유지합니다. 파일 읽기나 초기 백업에 실패하면 원본 보호를 위해 실행을 중단합니다.

## 기본 사용

- 오늘 / 앞으로 탭에서 입력 후 Return. Shift-Return은 줄바꿈입니다.
- 체크하면 완료 기록으로 이동합니다. 보관함 아이콘에서 복구할 수 있습니다.
- `+`는 새 상세 일정, `…`는 해당 일정 편집입니다.
- 항목에 잠시 머물면 옆에 상세창이 열립니다. 편집하거나 드래그하면 고정됩니다.
- 기존 일정의 상세 편집은 자동 저장됩니다. 새 일정은 **추가**를 눌러 저장합니다.
- 상세창 상단을 잡아 옮길 수 있습니다. 긴 메모는 화면 높이까지 확장되고 이후 스크롤합니다.
- 메뉴 막대에서 모니터 선택, 전체 화면 표시, 호버 일시 중지, 가져오기, 종료를 할 수 있습니다.
- Dock / ⌘Tab에 없으므로 종료할 때는 **메뉴 막대 → SideTodo 종료**를 이용하세요.

## 우선 확인할 것

1. Safari나 메모에 입력하는 도중 가장자리로 마우스를 옮겨도 원래 앱의 입력 포커스가 유지되는지.
2. 위젯에 클릭한 뒤 한글/영문 입력, 한글 조합 중 Return, 붙여넣기, ⌘Z, Shift-Return이 자연스러운지.
3. 긴 제목과 20줄 이상의 메모가 잘리지 않고 창이 확장되는지. 달력 선택이 저장되는지.
4. 호버 상세창으로 마우스를 옮길 때 닫히지 않는지. 편집을 시작한 후 밖으로 옮겨도 유지되는지.
5. 상세창을 다른 위치·모니터로 옮길 수 있는지. 다른 창에 가려질 때 메뉴 막대에서 다시 열리는지.
6. 완료 → 보관함 → 복구 후 제목·메모·날짜가 유지되는지. 앱 재실행 후에도 유지되는지.
7. 전체 화면 Safari, 데스크탑 전환, Mission Control, Stage Manager에서 표시가 적절한지.
8. Dock이 왼쪽에 있을 때, 외부 모니터 연결/해제, 잠자기 복귀 후 위치가 맞는지.
9. 시스템 설정의 동작 줄이기에서 창 애니메이션이 줄어드는지.
10. 완료 기록 JSON / Markdown 내보내기가 되는지.

자동 테스트는 모든 실제 조작을 대신하지 않습니다. 특히 전체 화면·Stage Manager·한글 조합·트랙패드 사용감은 이 프리뷰에서 수동 확인할 대상입니다.

## 피드백에 적어 주세요

- macOS 버전 / 칩(M1·M2 등 또는 Intel) / 모니터 개수
- 어떤 동작을 했는지 → 기대한 결과 → 실제 결과
- 가능하면 개인정보를 가린 화면 캡처나 짧은 영상

데이터 위치: `~/Library/Application Support/SideTodo/`.
실제 일정 파일에는 개인 메모가 있으므로 피드백에 파일을 통째로 첨부하지 않아도 됩니다.
테스트 종료 시 앱을 종료하고 응용 프로그램에서 삭제하면 됩니다. 일정 데이터는 별도 폴더에 남습니다.
