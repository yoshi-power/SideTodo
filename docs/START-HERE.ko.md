# SideTodo 시작하기

1. ZIP 파일을 원하는 폴더에 **모두 압축 해제**합니다.
2. `SideTodo.exe`를 실행합니다. 설치와 .NET 별도 설치가 필요 없습니다.
3. 화면 왼쪽 위에서 조금 내려온 위치의 작은 바 근처로 마우스를 옮깁니다.

Windows 10/11 64비트(x64)용입니다. 첫 실행은 포함된 런타임을 준비하느라 조금 더 걸릴 수 있습니다. 이 배포본에는 코드 서명이 적용되어 있지 않습니다.

## 쓰는 방법

- 빈 체크 줄에 입력 → **Enter**로 저장하고 다음 줄에 계속 작성합니다.
- **오늘 / 앞으로**로 분류합니다. 날짜가 지난 미완료 작업은 오늘에 남습니다.
- **+**: 메모와 날짜를 포함한 상세 일정. 상단을 잡아 옮길 수 있습니다.
- 항목에 잠시 마우스를 올리거나 **···**를 누르면 상세 내용을 확인하고 수정할 수 있습니다.
- 상세 창의 **완료 / Ctrl+Enter**는 내용을 저장합니다. 목록의 **체크박스**는 작업 완료 처리입니다.
- **▤ 완료 보관함**: 완료 기록 정렬, 복구, Markdown·JSON 내보내기.
- 상세 창에서 **× / Esc**는 저장하지 않고 닫기입니다. 편집 중인 호버 창은 자동으로 닫히지 않습니다.
- 종료하려면 시스템 트레이의 SideTodo 아이콘을 우클릭한 뒤 **종료**를 선택합니다. 작업 표시줄과 Alt+Tab에는 표시되지 않습니다.

## 내 데이터

`%LOCALAPPDATA%\SideTodo\tasks.json`에 저장됩니다. 바로 이전 저장본은 `tasks.json.bak`입니다. 자동 클라우드 전송은 없습니다.

다른 컴퓨터로 옮기려면 두 컴퓨터에서 앱을 종료한 뒤 이 파일을 같은 위치에 복사하세요. 새 버전으로 업데이트할 때는 앱을 종료하고 실행 파일을 교체하면 됩니다. 실행 파일을 삭제해도 할 일 데이터는 유지됩니다.

자동 시작은 기본 설정하지 않습니다. 원하면 Windows의 시작 프로그램 폴더에 `SideTodo.exe` 바로가기를 직접 추가하세요.
