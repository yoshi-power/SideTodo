# SideTodo for Mac · Preview 2

- 표시 바를 더 길고 밝게 만들고 어두운 테두리를 더해 밝은 화면에서도 구분되도록 했습니다.
- 빈 메모 칸의 클릭 영역이 줄어들어 입력하기 어려운 문제를 수정했습니다. 메모 가운데 클릭 → 한글 입력 → 자동 저장 → 다시 열기를 실제 AppKit 컨트롤로 검증했습니다.
- 위젯과 상세창은 크기를 유지하며 부드럽게 나타나고 사라집니다. 닫히는 도중 다시 열어도 뒤늦은 닫힘 처리가 재개방한 창을 숨기지 않습니다.
- 기존 일정 파일의 위치·형식과 앱 식별자를 유지합니다. 첫 실행 시 `tasks.before-preview2.json` 원본 백업을 한 번 만들고 덮어쓰지 않습니다. 미완료·완료 일정, 날짜, 메모 보존을 검증했습니다.

## 업데이트

기존 앱을 메뉴 막대에서 종료하고 **응용 프로그램 폴더의 SideTodo.app만 교체**하세요. `~/Library/Application Support/SideTodo/`는 삭제하지 마세요. 기존 일정은 새 앱이 그대로 불러옵니다.

`SideTodo-1.1.0-mac-preview.2-universal.zip`은 Apple Silicon·Intel 공용이며 macOS 13 이상을 대상으로 합니다. ZIP 안에 첫 실행·업데이트·테스트 안내가 있습니다.

현재는 Developer ID 서명·Apple 공증이 없는 프리뷰입니다. 첫 실행이 차단되면 신뢰하는 배포 파일인지 확인한 뒤 시스템 설정의 개인정보 보호 및 보안에서 확인 없이 열기를 이용하세요.

실제 기기에서의 한글 IME 조합, Spaces·전체 화면·다중 모니터 사용감은 계속 확인할 대상입니다.

함께 첨부된 Windows 1.0.1 ZIP에는 동일한 위젯 닫힘 애니메이션 개선이 들어 있습니다. Windows는 `%LOCALAPPDATA%\SideTodo\` 데이터를 유지하며 실행 파일만 교체하면 됩니다.
