# SideTodo

Windows 화면 왼쪽에 붙어 있는 작은 할 일 위젯입니다. 배포 ZIP에는 .NET 런타임이 포함됩니다. 소스에서 프레임워크 종속 방식으로 빌드한 경우에만 .NET 8 Desktop Runtime이 별도로 필요합니다.

## 실행

배포 ZIP을 압축 해제하고 `SideTodo.exe`를 실행하세요. 왼쪽 바에 마우스를 올리면 패널이 열립니다.

- **오늘**: 오늘 및 기한이 지난 미완료 작업. 날짜가 지나도 사라지지 않습니다.
- **앞으로**: 미래 날짜 작업과 날짜 없는 작업. 지정 날짜가 되면 오늘로 이동합니다.
- 화면 왼쪽에 **4×28px 바**만 남습니다. 바 주변 약 **40×100px**에 접근해도 체크리스트가 펼쳐집니다. 감지는 마우스 위치로 처리하므로 주변 앱을 가리는 큰 투명 창은 만들지 않습니다.
- 맨 아래 빈 체크 줄에 바로 쓰고 **Enter**를 누르면 저장되고 다음 빈 줄에 계속 적을 수 있습니다.
- 입력할 때 강조된 입력 영역, 더 큰 글자, 넉넉한 여백과 **↵** 저장 버튼이 나타납니다. Enter 후 약 1.1초 뒤 작아집니다.
- 기본 폭은 246px이며 긴 글에 맞춰 폭과 높이가 커집니다. 폭 560px를 넘는 글은 줄바꿈되며, 긴 목록은 스크롤합니다. 제목을 말줄임표로 자르지 않습니다.
- 체크한 항목은 부드럽게 사라집니다. 우클릭 메뉴 또는 트레이의 **완료한 일**에서 다시 볼 수 있습니다.
- 항목 제목은 그 자리에서 수정합니다. Enter 또는 포커스를 옮기면 저장됩니다.
- 작은 **+**는 중앙 상세 일정 창입니다. 메모와 날짜를 지정할 때 사용하세요.
- 상세 일정의 **오늘 / 앞으로 / 날짜 지정**은 흑백 선택 버튼입니다.
- **날짜 지정**은 상세 창 안에 흑백 월간 달력을 펼칩니다. 앞뒤 달 이동, 오늘로 이동, 날짜 선택을 지원합니다.
- 상세 창 상단의 **⠿ 일정** 영역을 잡아 원하는 위치로 옮길 수 있습니다.
- 메모 입력 영역과 창은 글 길이에 맞춰 넓어지고 길어집니다. 메모 안에 별도 스크롤바를 만들지 않으며 화면 높이를 넘으면 본문을 스크롤합니다. 상단과 완료 버튼은 계속 보입니다.
- 항목에 약 **0.5초** 마우스를 올리면 옆에 동일한 상세 편집 창이 열립니다. 마우스를 창으로 옮겨 메모·날짜를 확인하거나 바로 수정할 수 있습니다.
- 호버 창에서 클릭·입력·드래그하면 창이 유지됩니다. **완료 / Ctrl+Enter**로 저장하고, **× / Esc**로 취소합니다. 읽기만 한 창은 항목과 상세 창을 모두 벗어나면 잠시 뒤 닫힙니다.
- 항목에 마우스를 올리면 **···**가 나타납니다. 상세 수정과 삭제를 할 수 있습니다.
- 마우스가 나간 뒤 약 0.65초 지나거나 다른 창을 클릭하면 접힙니다. 입력 중에는 마우스를 옮겨도 바로 닫히지 않습니다.
- 미저장 입력은 실행 중에 탭별로 유지됩니다. 앱 종료 전에는 Enter로 저장하세요.
- 상단 탭과 + 사이의 빈 공간을 위아래로 드래그하면 높이가 저장됩니다.
- 시스템 트레이에서 열기, 추가, 위치 초기화, 종료를 할 수 있습니다.
- 입력 창: `Ctrl+Enter` 저장 / `Esc` 취소. 작성 중에는 자동으로 닫히지 않습니다.

데이터는 `%LOCALAPPDATA%/SideTodo/tasks.json`에 저장하고 이전 저장본은 `.bak`으로 보관합니다. 클라우드 전송 및 자동 시작 등록은 없습니다. 기본 화면은 주 모니터 왼쪽입니다.

위젯과 상세 일정 창은 작업 표시줄과 Alt+Tab 목록에 표시되지 않습니다. 다시 열거나 종료하려면 화면 왼쪽 바 또는 시스템 트레이를 사용하세요.

## 완료 보관함

상단 `+` 옆 **▤** 버튼으로 엽니다. 날짜 분류와 관계없이 완료한 모든 작업이 모이며 최근 완료순/오래된 완료순을 전환할 수 있습니다. **복구**하면 기존 제목·메모·예정일을 유지한 채 미완료 목록으로 돌아갑니다. 다시 완료하면 새로운 완료 시각으로 기록됩니다.

**내보내기**에서 Markdown(`.md`) 또는 JSON(`.json`)을 선택해 로컬 파일로 저장합니다. 생성 시각, 완료 시각, 예정일, 제목, 메모, 항목 ID를 포함하고, 오래된 완료부터 정렬합니다. AI에 전달할 파일을 직접 선택할 수 있도록 만든 기능이며 외부 전송은 하지 않습니다. 이전 버전의 완료 항목은 완료 시각을 알 수 없어 `시간 미기록` / `null`로 남깁니다.

## 빌드 및 검증

```powershell
dotnet build -c Release
dotnet publish -c Release -o publish --no-self-contained
./publish/SideTodo.exe --self-test
./publish/SideTodo.exe --ui-smoke
```

검증 결과는 실행 파일 옆 `self-test-result.txt`, `ui-smoke-result.txt`에 기록됩니다. 자체 검증은 임시 폴더만 사용하며 실제 할 일 데이터에 접근하지 않습니다. `--ui-test`는 실제 데이터와 분리된 수동 UI 검증 창을 엽니다.
