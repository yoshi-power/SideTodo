# SideTodo 1.0.0

화면 가장자리에 조용히 붙어 있다가 필요할 때 펼쳐지는 Windows용 할 일 위젯의 첫 배포 버전입니다.

## 포함된 기능

- 오늘 / 앞으로 분류, Enter로 이어 쓰는 인라인 체크리스트
- 입력 길이에 맞춰 넓어지는 UI와 완료 애니메이션
- 이동 가능한 상세 창, 항목 호버로 바로 열리는 편집 화면
- 흑백 달력과 긴 메모 작성
- 완료 보관함, 완료순 정렬, 복구, Markdown·JSON 내보내기
- 로컬 JSON 저장과 이전 저장본 백업
- 작업 표시줄·Alt+Tab 제외, 시스템 트레이 제어

## 다운로드와 실행

`SideTodo-1.0.0-win-x64.zip`을 압축 해제하고 `SideTodo.exe`를 실행하세요. **Windows 10/11 x64**, 설치 불필요, .NET 런타임 포함 배포본입니다. 사용자의 할 일 데이터는 포함되어 있지 않습니다.

`.sha256` 파일은 ZIP의 무결성을 확인하기 위한 체크섬입니다. 첫 실행 안내와 포함 런타임의 고지는 ZIP 안에 있습니다.

## 데이터 유지

데이터 위치는 `%LOCALAPPDATA%\SideTodo\tasks.json`입니다. 이전 버전을 종료한 뒤 실행 파일을 교체하면 기존 데이터를 계속 사용합니다. 이전 버전의 완료 항목은 완료 시각이 없으면 `시간 미기록`으로 표시됩니다.

## 검증 및 범위

런타임 포함 실행 파일로 데이터·복구·내보내기 테스트와 실제 Windows UI 회귀 테스트를 수행했습니다. 현재 배포는 x64 포터블 버전이며 코드 서명, 자동 업데이트, 자동 시작, 클라우드 동기화는 포함하지 않습니다.
