# Third-party notices

The self-contained Windows distribution includes the Microsoft .NET runtime and Windows Desktop runtime. Their license and third-party notice files are copied directly from the NuGet runtime packages into the distribution's `licenses` folder.

The application uses WPF and Windows Forms from these runtimes. No additional application-level NuGet packages are used.

Source references: https://github.com/dotnet/runtime and https://github.com/dotnet/wpf
